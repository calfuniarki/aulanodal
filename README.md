# Aula Nodal

Aula Nodal** es un espacio de formación y recursos para docentes que integran tecnología con sentido pedagógico.

Este repositorio contiene el sitio web oficial de Aula Nodal, donde se difunden cursos, materiales, recursos digitales y propuestas de formación para el aula.

---

## 🌐 Sitio web

🔗 [www.aulanodal.com](https://www.aulanodal.com)

---

## 📚 Acerca del proyecto

Aula Nodal nace con la misión de acompañar a docentes de habla hispana en el uso de herramientas digitales desde una mirada pedagógica, accesible y realista.

Buscamos que la tecnología no sea un obstáculo, sino un puente para mejorar la enseñanza, la planificación y la evaluación.

---

## 🧩 Secciones del sitio

- **Inicio** — Presentación general del proyecto.
- **Cursos** — Formaciones disponibles y próximas.
- **Recursos** — Materiales descargables para docentes.
- **Comunidad** — Espacio de intercambio y acompañamiento.
- **Contacto** — Canales de comunicación directa.

---

## 🛠️ Tecnologías

El sitio puede adaptarse a distintas arquitecturas. Estructura base sugerida:

- HTML5
- CSS3
- JavaScript
- Markdown para contenidos
- Despliegue estático

En caso de migrar a un generador estático o framework, esta base puede integrarse sin complicaciones.
